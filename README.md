# The No Theo License

A permissive software license for almost everyone.

The No Theo License is based on the MIT License, with one material change: the person publicly known as Theo Browne (`@theo`) receives no rights to the software.

## Use it

Copy [`LICENSE`](LICENSE) into your repository, then replace:

- `[year]` with the current year
- `[copyright holder]` with your name or organization

If your project uses SPDX metadata, use a custom identifier such as:

```text
LicenseRef-No-Theo-1.0
```

## Is this open source?

No. A license that excludes a person does not meet the Open Source Definition. Call the software **source-available under the No Theo License**.

## Why?

Because apparently named-exclusion licenses are a genre now.
